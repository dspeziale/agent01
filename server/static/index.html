Installa Nuova Sonda

Esegui uno dei comandi seguenti direttamente nel terminale del computer o server da monitorare. L'agente si configurerà automaticamente come servizio di background persistente.

🪟 WINDOWS (PowerShell come Amministratore)
irm https://simei.dsc-italy.app/install.ps1 | iex
🐧 LINUX (Terminale con sudo sh)
curl -fsSL https://simei.dsc-italy.app/install.sh | sudo sh
Alternativa con wget: wget -qO- https://simei.dsc-italy.app/install.sh | sudo sh
🔍 SONDA DI DEBUG A VIDEO (Diagnostica istantanea a schermo)
Se la sonda sembra installata ma non compare nella lista, esegui la sonda di debug per vedere tutti i dettagli a video (DNS, SSL, Task, invio HTTP in tempo reale):
Windows: irm https://simei.dsc-italy.app/debug.ps1 | iex
Linux: curl -fsSL https://simei.dsc-italy.app/debug.sh | sudo sh
